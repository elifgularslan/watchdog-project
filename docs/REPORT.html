Term Project 1: POSIX Signal-Based Process Monitoring and Management System (Watchdog)

1. Project Architecture and System Design

This project implements a supervisor program (referred to as the watchdog) that creates, monitors, and manages a set of child processes using standard POSIX system calls. The application tracks the life cycle of its child processes, detects crashes, restarts processes that terminate unexpectedly within a defined limit (at most 3 times), responds safely to asynchronous POSIX signals (SIGINT, SIGTERM, SIGCHLD, SIGUSR1, SIGALRM), and logs all lifecycle events with precise timestamps.

1.1. Modular System Structure

The system is organized into four modular, decoupled components:

  • Signal Manager & Main Loop (src/main.c, src/signal_manager.c): Installs signal handlers via sigaction(), maps asynchronous events to async-signal-safe flags, coordinates the main event polling loop, and orchestrates graceful shutdown.
  • Process Manager (src/process_manager.c, workers/worker.c): Creates worker processes via fork() and execv(), maintains the process status table, reaps terminated processes via non-blocking waitpid(), and sets up interval timers for health monitoring.
  • Restart Manager (src/restart_manager.c): Evaluates termination causes, enforces the strict maximum 3 restart limit per process, avoids infinite restart loops, and implements the 5-second shutdown timeout with SIGKILL fallback.
  • Logger Module (src/logger.c): Writes timestamped lifecycle records to watchdog.log and formats comprehensive child process status reports upon receiving SIGUSR1.

1.2. Required POSIX Mechanisms and System Calls

  • sigaction() & Async-Signal Safety: Handlers are strictly async-signal-safe. Complex I/O or memory allocation is avoided inside handlers; they only record state transitions in volatile sig_atomic_t flags, delegating processing to the main loop.
  • fork(), execv(), and _exit(): Workers are spawned using fork() and replaced via execv(). On execution failure, _exit(EXIT_FAILURE) is called to prevent duplicate flushing of inherited standard I/O buffers.
  • waitpid() (WNOHANG & EINTR): Reaps finished children to prevent zombie processes. It handles EINTR signals and differentiates normal exit (WIFEXITED, exit code 0) from application errors (exit code != 0) and uncaught signals (WIFSIGNALED).
  • setitimer() & SIGALRM: Sets a real-time interval timer (ITIMER_REAL) for periodic process table health inspections and timeout enforcement.
  • kill(): Dispatches termination signals (SIGTERM, SIGKILL) with error validation.

  • Ctrl+C (SIGINT) Scenario: Sending Ctrl+C in the active terminal initiated the graceful shutdown sequence, terminating all children cleanly without resource leaks.
